**Project Description:**

This project focuses on developing a Python-based mutual fund portfolio planning and analysis application. It uses financial data analysis, portfolio construction, and risk assessment techniques to evaluate investment performance and potential returns.

The project includes:
- Mutual fund data preparation and exploratory data analysis.
- Annualized return and volatility calculations.
- Sharpe Ratio and Sortino Ratio analysis.
- Portfolio construction and diversification.
- Risk and return evaluation.
- Monte Carlo simulation to explore potential investment scenarios.
- Interactive portfolio planning dashboard using Streamlit.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, and Streamlit.

**Dataset:** A synthetically generated mutual fund dataset is used for educational and analytical purposes due to the unavailability of an actual database.

The project demonstrates how Python and financial analytics can be used to evaluate investment portfolios, understand risk-return relationships, and support data-driven investment planning.
